# SunoSaver 🎵

Telegram бот для скачивания треков с **Suno AI** в формате **MP3** и студийном **WAV**, а также получения текстов песен.

## Возможности
- ⚡️ **Прямое скачивание**: автономное извлечение защищённого аудиопотока Suno через гостевые права и CDN (без внешних сервисов).
- 🎼 **Скачивание WAV**: конвертация трека в несжатый PCM WAV студийного качества (с автоматической адаптацией под лимит 50 МБ Telegram).
- 📜 **Текст песни**: извлечение слов / prompt песни в виде интерактивной кнопки.
- 💾 **Кэширование**: мгновенная повторная отдача через Telegram `file_id` (0% нагрузки на сервер).
- 🏷 **ID3-теги**: автоматическая прошивка названия и исполнителя в MP3.
- 🌐 **Многоязычность**: поддержка русского и английского языков.
- 🛡 **Отказоустойчивость**: 3 уровня резервных каналов скачивания.
- 👥 **Админ-панель**: статистика (`/stats`), бан/разбан пользователей (`/ban`, `/unban`).

## Установка и запуск

1. Склонируйте репозиторий:
   ```bash
   git clone <repo_url>
   cd sunosaver
   ```

2. Создайте виртуальное окружение и установите зависимости:
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ```

3. Убедитесь, что установлен `ffmpeg`:
   ```bash
   # macOS
   brew install ffmpeg

   # Ubuntu / Debian
   sudo apt update && sudo apt install -y ffmpeg
   ```

4. Скопируйте `.env.example` в `.env` и укажите ваш токен бота:
   ```bash
   cp .env.example .env
   nano .env
   ```

5. Запустите бота:
   ```bash
   python3 bot.py
   ```

## Деплой на сервере
Скрипт автоматического обновления:
```bash
./deploy.sh <IP_СЕРВЕРА>
```
